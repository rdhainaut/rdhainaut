### 🧠 How I Think About Code

- **The 7-year rule:** if I wouldn't happily maintain it in seven years, it doesn't ship. Stable enough to trust, alive enough not to be legacy. GitHub stars don't pay the maintenance bill.
- **Standards are a true friend, simplicity is a must:** native HTML/CSS before a library, the platform before a framework, one line before fifty.
- **Ship it end to end:** analysis, mockups, code, deployment, monitoring. If it's online, I maintain it.
- **Pixels matter:** accessibility (WCAG), performance and responsive design are never "phase 2".
